## Style guidelines (from original prompt)

- Read before recommending. Use Read/Bash, don't go from intuition.
- Ask before changing. Use AskUserQuestion when there are meaningful tradeoffs.
- Group questions into rounds (4-question max per round).
- Show proposed changes as diffs before applying.
- Prefer fewer changes. Lean philosophy: drop unless explicitly kept.
- Stay scoped to ~/.config/nix-darwin/.

## 2. Decisions reached this session

### Caddy / dnsmasq / mailpit (the stated highest-priority gap)

- **System-level launchd** (not per-project devenv-local Caddy).
- **Single multi-site Caddyfile** at `/etc/caddy/Caddyfile`, generated by
  `darwin/services.nix` via `environment.etc."caddy/Caddyfile".text`.
- That Caddyfile imports `/Users/<username>/.config/caddy/sites/*.caddy`,
  so adding a new site = drop a 3-line file in that dir + reload Caddy.
- Caddy itself runs via `launchd.daemons.caddy` (root, so it can bind 80/443)
  — `services.caddy` does NOT exist in this nix-darwin version.
- dnsmasq via `services.dnsmasq.addresses.test = "127.0.0.1";`. macOS
  resolver wired up via `environment.etc."resolver/test"` with
  `nameserver 127.0.0.1`.
- mailpit via `launchd.user.agents.mailpit` (user-level, since
  1025/8025 are unprivileged). Autostart at login.
- **Caddy bootstrap**: empty sites dir + commented template
  (`~/.config/caddy/sites/example.test.caddy`) — user adds real
  sites later, on their own. Per-port allocation is manual.

### HM module migration (was half-done)

- User chose "move ALL configs into Nix" (max declarative).
- **starship**: `programs.starship.settings = lib.importTOML ./starship.toml;`
  — full 204-line config preserved as `home/starship.toml`.
- **atuin**: HM stub `settings = { }` dropped (the dotfile was 100%
  commented defaults; no porting needed).
- **btop**: `xdg.configFile."btop/btop.conf".source = ./btop.conf;` —
  full config copied into the flake, with the dead brew theme path
  `/opt/homebrew/Cellar/btop/1.4.5/share/btop/themes/tokyo-storm.theme`
  replaced with bare name `"tokyo-storm"` (btop resolves from its
  own pkg share dir).
- **lazygit**: `programs.lazygit.settings = { git.pagers = [ { colorArg = "always"; } ]; };` (inline, trivial).
- **ghostty**: `xdg.configFile."ghostty/config".source = ./ghostty/config;`
  (we did NOT use `programs.ghostty` — its option availability across
  HM versions is uncertain; xdg.configFile works regardless).
- **zellij**: `xdg.configFile."zellij/config.kdl".source = ./zellij/config.kdl;`
  (KDL is awkward as a Nix attrset; raw file copy is the lean path).
- **htop**: NUKED — `programs.htop` removed from `home/tools.nix`.

  get it). Previously only on personal.
- `hosts/work.nix` adds `homebrew.casks = [ "slack" "zoom" "1password" ];`
